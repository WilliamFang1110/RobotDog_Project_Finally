# DreamDog‑RobotDog 四足机器狗
> ESP8266 裸机环境实现的四足机器狗，浏览器Web控制，无需APP，直连设备热点即可完成操控。

## 项目介绍
本项目基于ESP8266在裸机（无操作系统）环境下完成整套四足机器狗开发，不引入RTOS实时操作系统，完全依靠主循环、中断与状态机调度管理全部硬件任务，涵盖底层外设驱动、四足步态逻辑、OLED显示、WiFi异步Web服务、前端交互等完整链路。

早期原型版本大量使用 `delay()` 函数做舵机时序，裸机单循环架构下缺陷十分突出：执行运动动作时主循环被阻塞，网页服务无响应、串口语音指令丢失、屏幕停止刷新，多个任务无法并发运行。
针对裸机开发这一痛点，我将全部运动逻辑重构成 `millis` 时间分片的非阻塞状态机，彻底移除 `delay` 延时。改造之后，在裸机框架下实现舵机运动、串口语音解析、HTTP网络请求、OLED屏幕刷新、按键输入多任务并行运转，互不阻塞，大幅提升整机稳定性，充分挖掘裸机方案资源占用小、执行路径可控的优势。

设备工作在AP热点模式，手机或者电脑连接机器狗发出的WiFi，访问 [http://192.168.4.1](http://192.168.4.1) 就能打开控制面板。
网页资源不依赖外部服务器，全部存放在ESP8266的SPIFFS文件系统；WiFi账号、各类API密钥可以在网页配置页填写，参数持久保存在芯片Flash，断电不会丢失。

联网之后可以对接第三方接口：获取百度IP定位、心知天气实时气象数据，配合NTP服务获取网络时间，所有信息都可以在OLED屏幕展示。
同时接入ASR‑PRO语音识别模块，串口接收语音解析后的指令，实现语音控制机器狗运动和切换屏幕表情页面。

## 主要功能
- **Web网页无线遥控**
  AP热点直连，不需要路由器，手机电脑浏览器直接操控
  运动动作：前进、后退、左转、右转、坐下、躺下、肢体摆动、休眠归位
  自由模式：自动随机执行动作与表情
  OLED多套自定义表情切换
  硬件状态监测
  ADC采集电池分压，计算电压与电量百分比
  网页实时查看电池状态

- **联网拓展功能（需要连接外部WiFi）**
  NTP网络授时，OLED显示年月日、时分秒、星期
  百度IP定位，解析省市、经纬度并屏幕展示
  心知天气API获取实时温度、天气状况，配套天气图标显示

- **网页在线配置**
  网页填写外网WiFi信息、心知天气、百度地图密钥
  配置保存到Flash，上电自动加载尝试联网

- **语音识别控制**
  ASR‑PRO模块串口通信，唤醒词：星期六
  语音下达指令，控制运动、切换表情与显示页面

- **OLED 128*64 I2C显示屏**
  自定义表情点阵图像
  显示网络时间、定位、天气、设备IP、未联网提示

## 技术栈
### 固件端
- 主控：ESP8266 NodeMCU，裸机开发（无RTOS）
- 语言：C/C++ Arduino框架
- 开发环境：VS Code + PlatformIO
- 核心库：Servo、U8G2、ESPAsyncWebServer、ArduinoJson、NTPClient
- 关键实现：裸机非阻塞状态机、millis时间分片、SPIFFS文件系统、串口协议解析、中断按键、HTTP网络请求

### 前端
- HTML + 原生JavaScript，零外部依赖，轻量化页面
- 三个页面：首页、遥控控制台、参数配置页
- Fetch异步请求完成前后端交互，下发指令、轮询设备状态

### 外设硬件
- 多路舵机实现四足步态
- SSD1306 I2C OLED显示屏
- ASR‑PRO语音识别模块
- 电池分压检测电路
- 实体输入按键

## 项目遇到的问题与解决思路
1. **裸机环境下delay延时造成整个系统阻塞**
早期版本舵机动作依靠delay，裸机单循环架构，一旦进入延时，网页、语音、屏幕全部卡死。
解决方案：把每个动作拆解为状态机结构体，millis时间分片替代delay，在裸机框架下实现多任务协同，各个任务互不干扰。

2. **网页资源管理麻烦**
一开始尝试把HTML字符串硬写在C++代码，修改页面就要重新编译固件，维护繁琐。
解决方案：使用SPIFFS独立存放网页资源，单独打包spiffs.bin，修改前端页面不需要改动业务逻辑代码。

3. **第三方JSON接口解析、中英文城市适配**
百度IP定位拿到中文城市名称，而知心天气接口需要城市名；写映射函数，把中文省市转为英文适配API入参，ArduinoJson处理接口JSON报文。

4. **串口语音指令容易乱码、误触发**
ASR‑PRO串口输出拼音指令，容易残留换行空格垃圾字符。
解决方案：读取完整一行串口数据，做trim清除空白，读取完成清空缓冲区，避免残留字符造成误触发。
